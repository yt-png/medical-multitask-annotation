## Data Flow Freeze

Current V1 main path (no `prelabels/`, no model prediction as input):

```text
preprocess
  ↓
package
  ↓
task_packages/<batch>/{seg,det,cap}/
  ↓
ls-import  (empty tasks; data only)
  ↓
Label Studio (human annotation)
  ↓
export-split  (current/ + normal/ + rework/)
  ↓
rework-import  (only if rework remains; previous_annotations ≠ prediction)
  ↓
merge  (three-task current ready → final/)
```

Gold standard comes only from human `annotation`. Empty / missing payload → `rework/`.
